# Design

## 太刀（必做）

| 名称 | World 零件 | 第一版做法 |
|---|---|---|
| 集中转向 | 出招锁朝向 | 只在出招起手对齐镜头，挥刀中途不改轨迹 |
| 赤刃斩 I/II/III | 直斩 / 纵斩 / 上捞 | 红刃下加速现有斩击，一段补第二下命中 |
| 看破斩·旋 | 看破斩 | 红刃加宽窗、扣红刃时间而非清空槽，成功后接已有回旋当第二下 |
| 练解 | 气刃兜割 | 兜割后短输入窗，接到则播已有多段斩并加动作值 |

冰原已有看破、特殊纳刀、小居合、大居合、兜割。这些不改，只在红刃和兜割后加层。

## 片手（第二刀）

| 名称 | World 零件 | 第一版做法 |
|---|---|---|
| 防御斩加强 | 防御斩 | 动作值 + 挥刀帧挂攻击守势窗 |
| 反击斩 | 攻击守势窗 | 守势成功 → 松防御 → 轻攻击，派生高动作值斩 |
| 旋风刈 | 回旋斩 | 特定连段结束后的回旋斩升动作值、多 1 段 |

## 施工顺序

1. 太刀出招起手转向
2. 红刃状态机
3. 看破旋 + 练解
4. 片手守势反击
5. 旋风刈

## 键位冻结

- 练解：兜割后再次特殊攻击 / R2
- 反击斩：守势成功后松开防御再点轻攻击，不和滑步斩抢同一帧
